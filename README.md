# Natural Chinese Writing Skill

帮助 AI 在专业写作、提案、研究和项目移交中使用自然、清晰的中文，并保留原意、事实、数字和必要条件。

技能基准为 colleague_v01_20261107，语言规范 v02。完整技能目录见 [studio-work-standards](studio-work-standards/)，安装和验证步骤见 [安装说明](install_and_test.md)，也可下载仓库中的技能 ZIP。

日常自动触发取决于平台与具体任务，安装后请按说明验证。个人可参考反馈模板独立维护版本，技能不会自动更新其他人的副本。

WorkBuddy 和 ZCode 的实际安装及自动触发尚待在对应设备验证。
