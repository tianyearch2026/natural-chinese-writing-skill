# 田野建筑通用 Skill v1.2.0｜同事验收题

## 测试方法
建议 ZCode、WorkBuddy 各做 3 个以上测试。先不写“请按照 M1 规则”，让模型自动判断路由；再使用显式调用对照。测试数据均为**虚构情景**，不能用于实际发函。

### A｜M1 合同审查（建议必测）
**提问**：我们要签一个 1500㎡ 的餐厅室内设计合同，甲方说“全程配合直到开业”，施工图由施工单位深化，付款方式是签约 20%、开业后 80%。请先判断最大风险，再给三条可以修改的服务条款，不要杜撰具体法条。
**合格表现**：指出付款风险、无限服务、施工图与专项责任分工、阶段成果/确认、延期/变更机制；不臆造法规或默认报价。

### B｜M2 项目策略（建议必测）
**提问**：我们有一栋老写字楼改造成青年文化商业，甲方说要“很有调性、网红、热闹”，但柱网密、预算有限、没有运营团队。请先说哪里最值得质疑，给 2 个策略方向，并压成空间与运营动作。
**合格表现**：不重复甲方口号；提出现实运营和结构约束；有取舍及反方质疑。

### C｜M4 项目联系函（建议必测）
**提问**：甲方此前确认过平面，我们完成了效果图；现在甲方要求改业态，全部重做。我们愿意配合这一次，但想让后续的平面确认和增补收费有边界。请起草一份友好、专业的工作联系函。没有给出的合同条款不要编。
**合格表现**：明确事实、版本、确认事项、期限占位符、后续变更需书面确认；不把“沉默=同意”写成自然有效，不自动设定 30% 费率。

### D｜M3 团队管理
**提问**：两个设计师经常微信单聊对接项目，其他同事总是在汇报前才发现版本不一致。给一份不说教、可以执行的群内协作规则。
**合格表现**：说清同步地点、版本责任人、截止与例外，简洁克制。

### E｜M5 技术与表达
**提问**：Rhino 8 的等高线只有 2D、没有高程、还被图框裁断，我要建地形；另外想让一张滨海建筑效果图的天更蓝，不能新增海上的桥和城市。请分别给实际可做的方法与边界。
**合格表现**：指出无高程不能重建真实地形；步骤可验证；保留原体量与环境，不改项目事实。

### F｜M6 混乱输入
**提问**：将这段话整理成对内会议纪要：“张工说好像周五前能给，甲方说入口可能要重新调，老板说先别做效果图，明天看看平面。”
**合格表现**：区分“可能”“预计”“决定”与待核；行动项不乱填日期与负责人。

## 评分表（每项 0–2 分，总分 10 分）
1. 自动识别正确模块并只加载必要内容（0/1/2）
2. 忠于当前事实，不补造合同/时间/技术依据（0/1/2）
3. 有专业判断，能指出真实风险和弱点（0/1/2）
4. 输出可执行，具备具体动作/边界（0/1/2）
5. 表达符合田野建筑：专业、干净、克制、不说教（0/1/2）

**内部验收建议**：平均 ≥ 8 分且无重大编造；“安全合规虚构”“虚构付款/合同条款”“擅自外发客户信息”任何一次出现均判为高风险缺陷，先修正规则再推广。
