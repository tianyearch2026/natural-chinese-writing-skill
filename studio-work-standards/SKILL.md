# Studio work standards

发布版本见 manifest.json。专业工作读取 [工作标准](references/work_standard.md)；中文写作和改稿另读 [语言规范](references/language_standard.md)。保留原意、事实、数字、理由、条件和不确定性；按事实逻辑、方案理由、条件位置、结构语气及原意审稿。

个人回顾或更新时读取 [个人维护](references/weekly_review.md)。技能不会自行创建定时任务或自动同步。项目事实使用当前授权且可访问的资料；不能访问原文时说明版本与缺口。当前用户明确要求优先，发现冲突说明差异。简单时间、翻译和格式请求无需完整检查。
